# Repository Hub: Staff Notes

Cobblestone Learning · *Learning. Creativity. Trust.*

The Repository Hub shows everything that we have built for our learning sites, in one place. You can browse it like a catalogue, learn what each project does, and try the demos. You do not need to know how GitHub works.

## What you can do with it
- **Discover**: start with demos to try, recent changes, and projects grouped by the job they do.
- **Map**: see every project as a stone, grouped by purpose. Type in the search box to light up stones.
- **Learner journey**: follow a learner from sign-in to the final report, and see what helps at each step.
- **Connections**: see which projects work with LearnDash, BuddyBoss, WooCommerce and other platforms.
- **Sites**: see the work that runs on each live site.
- **What's new**, **All projects** and **Words explained**: recent changes, a full list with filters, and plain explanations of the words on the page.

## How to use it
1. Open https://cobblestonelearning.github.io/ in your browser.
2. Select **Sign in with GitHub**. Without signing in, you see only our few public projects.
3. Select one of the four header cards, or a tab such as **Map** or **Learner journey**.
4. Select any project to open its page. The page shows what the project does, pictures, step-by-step guides and the staff notes.
5. To see more technical detail, set **Detail** to **How it's built** or **Code**.
6. To share a page, select **Copy link** and paste the link in a message.

## Good to know
- Everyone in the Cobblestone Learning organisation can see every project. A project page shows your access: **Read** means that you can look only, and **Write** means that you can make changes.
- Managers also see a **Manage** link in the page header, for people, teams and access.
- Each project page uses the project's own details: its staff notes, and the `hub/project.json` file with its pictures and guides. Projects that have no pictures yet show a generated picture.
- This repo is public, because the hub is a public web page. Never put passwords, keys or client details in it.
- Your sign-in lasts until you close the tab. Sign out on a shared computer.
- A project page address that ends in `?launch=demo` opens the demo of that project immediately. If you have not signed in, the hub asks you to sign in first.
