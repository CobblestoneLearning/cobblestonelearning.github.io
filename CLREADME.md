# Repository Hub: Staff Notes

Cobblestone Learning · *Learning. Creativity. Trust.*

The Repository Hub is a web page that lists all of our projects on GitHub in one place. You can find a tool, read a short plain-language note about it (like this one), and open it, without needing to know your way around GitHub. It is for the team's own use, not a marketing site.

## What you can do with it
- Browse our projects grouped by purpose, such as authoring, reporting, translation and tools.
- Search by name or by what a tool works with.
- Open a project's **Details** to read its staff notes, or its technical README.
- Open a live demo, where a project has one.
- Switch between **Organisation** (everything) and **Mine** (your own projects and the ones you have worked on recently), once you are signed in.
- Switch to **Developer view** to browse code and files and copy the command for downloading a project.

## How to use it
1. Open https://cobblestonelearning.github.io/ in your browser.
2. Stay in **Staff view** (the default) to see projects by purpose.
3. Click **Sign in** with your own GitHub account to see our private projects as well. Without signing in, you only see the few public ones.
4. Click **Details** on any project to read about it.

## Good to know
- Everyone in the Cobblestone Learning organisation can see every project. Each card shows what you can do with it: **Read** means look only, **Write** means you can make changes, **Admin** means you can also change its settings.
- Managers also see a **Manage** link at the top. It opens a page for seeing who has access to what, and for changing it.
- This repo is public, because the hub is published as a public web page. Never put anything private in it, such as passwords, keys or client details.
- Signing in only lets you see what your own GitHub account already has access to. Your sign-in lasts until you close the tab; sign out on a shared computer.
- The hub reads everything live from GitHub, so a new project appears as soon as it is added.
